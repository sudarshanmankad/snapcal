Fitness Move (clipboard only)

Update never opens Shortcuts. Automations copy Active Energy to the clipboard; SnapCal only reads the clipboard when you open the Home Screen app or tap Update — so you stay in SnapCal. Stale/lower clipboard values are ignored (or confirmed) so they can’t wipe a good Move.

1) Find Health Samples → Active Energy → today → Fill Missing OFF
2) Calculate Statistics → Sum
3) Round Number → Sum → Integer
4) Text → SNAPCAL_MOVE= · Combine Text → Text + Rounded → Copy to Clipboard
5) Do not add Open URLs
6) Name exactly SnapCal Move

Automation: Shortcuts → Automation → + → Time of Day → Run Shortcut → SnapCal Move → Ask Before Running OFF. Add one per time (e.g. 8:00, 12:00, 16:00, 20:00). Phone unlocked.
